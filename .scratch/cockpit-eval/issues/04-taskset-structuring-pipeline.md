# 04: 任务集结构化流水线

**What to build:** 把现有"用户指令 + 期望结果"语料（目前未统一结构化）转为完整合法的 cockpit 任务集（<50 个任务）：每条指令生成 user_scenario（指令 + persona，画像在限定范围内生成、user_id/VIN 与测试环境一致）、每条期望结果按 03 验证过的措辞范式拆 3~6 条原子断言、`reward_basis` 设为 `["nl_assertions"]`，全量通过 `tau2 check-data`。

**Blocked by:** 03（首次端到端冒烟跑——断言措辞先在种子任务上验证）

**Status:** ready-for-agent

- [ ] 全部语料转为结构化任务，`tau2 check-data` 全量通过
- [ ] 每个任务的期望结果均为原子断言列表，措辞遵循 03 的试错结论
- [ ] persona 的画像细节限定在与测试后端一致的范围内，避免模拟器编造失真信息
